Capillary Flow Calculator Neo is a rewritten JavaScript/browser version of the original VB6 workflow. This tool runs on Windows, macOS, and Linux through a web browser while keeping the core capillary flow calculation features.

Modified for easier use for nanoflow-LC people. New features include system pressure calculation for summing pressure contributions from all LC tubing/components, as well as gradient pressure calculation that considers solvent B composition changes along the column during gradient runs.

This tool is intended to provide practical calculation references for LC users and help with LC troubleshooting. Our goal is no leaking, no clogging, no air bubbles.

Browser version adapted by Siqi from selected workflows of the PNNL VB6 Molecular Weight Calculator.
